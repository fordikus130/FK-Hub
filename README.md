## ✨ Главные возможности

* **Дизайн Windows 11 Fluent UI** — гармоничный интерфейс с поддержкой тёмной, светлой и автоматической системной темы.
* **Мультиязычность** — мгновенное переключение между русским и английским языками интерфейса.
* **Прямая работа с Windows API и реестром** — никаких медленных заглушек, все изменения выполняются напрямую и проверяются при запуске.
* **Безопасность системы** — возможность создания контрольной точки восстановления системы перед применением любых твиков.
* **Встроенное автообновление** — проверка актуальных версий напрямую с GitHub Releases в один клик.

## 🚀 Быстрый старт и установка

Перейдите на страницу [**Релизов (Releases)**](https://github.com/fordikus130/FK-Hub/releases/latest) и выберите подходящую версию:

| Файл | Описание |
| :--- | :--- |
| **`FK-Hub-Setup-1.0.0.exe`** | **Мастер установки (Рекомендуется)**. Создаёт ярлыки на рабочем столе и в меню Пуск, автоматически запрашивает права администратора. |
| **`FK-Hub-Portable-1.0.0.exe`** | **Портативная версия**. Не требует установки, работает из одного исполняемого файла, идеально для запуска с USB-накопителя. |

> [!NOTE]
> Приложение требует запуска с правами **Администратора** для успешного применения системных твиков и управления системными службами Windows.

## 🧩 Разделы программы

### ⚡ Оптимизация системы
* **Фоновые приложения (UWP)** — полное отключение фоновой активности встроенных UWP-приложений Windows.
* **Службы оптимизации доставки** — отключение служб `DoSvc`, отчётов об ошибках `WerSvc` и брокера карт `MapsBroker`.
* **Microsoft Edge в фоне** — запрет фоновой работы браузера Edge и функции Startup Boost.
* **Гибернация и быстрый запуск** — освобождение дискового пространства за счёт отключения `hiberfil.sys`.
* **Телеметрия и слежка** — отключение служб диагностического трекинга (`DiagTrack`, `dmwappushservice`) и рекламного ID.
* **Искусственный интеллект Copilot** — полное отключение компонентов Windows Copilot и AI.
* **Затемнение экрана UAC** — отключение зависания и затемнения рабочего стола при запросах контроля учётных записей.
* **Задержка меню и обои** — уменьшение отклика всплывающих контекстных меню до 20 мс и отключение сжатия JPEG-обоев рабочего стола.
* **Рекомендации в меню Пуск** — отключение рекламы и рекомендуемых файлов в Windows 11.
* **Акселерация мыши (EPP)** — включение честного линейного отклика мыши (1:1) без аппаратного ускорения Windows.
* **Залипание клавиш** — отключение назойливых всплывающих окон при пятикратном нажатии Shift.
* **Запись игр (GameDVR)** — отключение фоновой записи Xbox Game Bar для повышения FPS в играх.
* **Сетевой троттлинг мультимедиа** — снятие искусственных ограничений пропускной способности сети при воспроизведении медиа.
* **Высокоточный таймер** — активация глобального разрешения системного таймера (`GlobalTimerResolutionRequests`).

### 📂 Настройка Проводника
* **Классическое контекстное меню** — возврат полноразмерного контекстного меню Windows 10 без кнопки «Показать дополнительные параметры».
* **Начальная папка «Этот компьютер»** — открытие Проводника сразу на локальных дисках вместо раздела «Главная».
* **Очистка боковой панели** — удаление разделов «Главная» (Home), «Галерея» (Gallery) и «Сеть» из левого дерева навигации.
* **Конфиденциальность** — очистка и отключение показа недавних файлов и часто используемых папок в быстром доступе.
* **Файловая система** — принудительное отображение расширений зарегистрированных файлов и скрытых папок.

### 🌐 Сеть и Диагностика
* **Точка восстановления** — создание контрольной точки восстановления системы `FK_Hub` через VSS и SystemRestore.
* **Очистка кэша и Temp** — быстрая очистка временных файлов пользователя, системного каталога `Temp` и графических кэшей шейдеров DirectX/OpenGL/NVIDIA/AMD.
* **Перезапуск Explorer** — мягкий перезапуск оболочки проводника без необходимости перезагрузки ПК.
* **Сброс сети** — очистка DNS-кэша (`ipconfig /flushdns`), сброс сетевого каталога Winsock и протоколов TCP/IP.
* **Сетевые подключения** — мгновенный вызов апплета `ncpa.cpl`.
* **Тест задержки (Ping)** — интерактивная проверка качества связи с популярными DNS и игровыми узлами.
* **Проверка целостности** — запуск восстановления системных файлов через `SFC /scannow` и `DISM /RestoreHealth`.

## 🛠️ Сборка из исходников

Если вы хотите собрать проект самостоятельно:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/fordikus130/FK-Hub.git
cd FK-Hub

# 2. Установите зависимости
npm install

# 3. Запуск в режиме разработки
npm start

# 4. Сборка установщика (NSIS)
npm run dist

# 5. Сборка портативной версии (Portable)
npm run dist:portable
```
